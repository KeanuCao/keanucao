## 💼 职业轨迹

### 合肥力动软件技术有限公司 | 技术合伙人 / 核心研发
**2022.04 - 2026.09**

作为“技术合伙人”，我主要负责技术方向、核心模块编码和团队协调。我们做了一款面向大型企业的 GUI 自动化巡检系统。

**几个比较有成就感的结果：**
- 系统在客户核心业务割接后 30 分钟内自动完成 400 个核心功能点巡检，精准发现 2 个隐藏缺陷。
